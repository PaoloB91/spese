# Spese

App personale per tenere il conto delle spese di casa fra due persone: chi ha pagato, di chi era la spesa, chi deve quanto. Un pulsante azzera il conto quando ci si mette a posto.

Una sola pagina HTML, funziona offline e si installa sulla schermata Home. I dati stanno sul telefono e in un archivio privato separato: questo repository contiene solo il codice.
